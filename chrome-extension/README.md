# Apex Auto — расширение Chrome: лот Copart/IAAI → пост

Собирает **все данные лота** со страницы аукциона (Copart, IAAI), считает цену «под ключ до Кишинёва»
по формулам калькулятора apexauto.md и одной кнопкой публикует пост в Telegram-канал,
на страницу Facebook и в Instagram.

## Установка

1. Chrome → `chrome://extensions`
2. Включить **Режим разработчика** (справа сверху)
3. **Загрузить распакованное расширение** → выбрать папку `chrome-extension`
4. Откроется страница настроек — заполнить Telegram и (по желанию) остальное

Обновили код — на карточке расширения нажать «Обновить» (⟳).

## Как пользоваться

1. Открыть лот на `copart.com/lot/...` или `iaai.com/VehicleDetail/...`
2. Открыть панель одним из трёх способов:
   - **иконка расширения в тулбаре** — выпадающая панель 800×600 (потолок Chrome для popup);
   - кнопка **⤢** в её шапке — та же панель в **боковой панели Chrome**: во всю высоту окна
     браузера, не закрывается при клике мимо, ширина тянется мышью за край;
   - красная кнопка **APEX → пост** внизу справа на странице лота — панель поверх аукциона.
3. Раскладка широкого окна: шапка лота на всю ширину, под ней **расчёт слева и текст поста
   справа одной высоты**, ещё ниже — лента фотографий во всю ширину. В узкой панели всё то же,
   но одной колонкой:
   - **шапка лота** — марка/модель, номер лота, повреждение и статус торгов, ссылка на лот.
     Характеристики намеренно не дублируются: они и так на экране аукциона и уходят в текст поста;
   - **расчёт под ключ** — поле «Ваша ставка» (кнопка рядом подставляет текущую ставку лота) и
     тёмная плашка с итогом. Клик по плашке разворачивает **построчную смету**: сбор аукциона,
     доставка до порта с маршрутом, море, страховка, услуги и растаможка с расшифровкой акциза —
     видно, откуда взялась каждая цифра. По умолчанию свёрнута: итог и так уходит в текст поста.
     Тип кузова, топливо и площадка аукциона стоят прямо под ставкой — всё определяется
     автоматически, но каждое поле можно поправить. Площадка выбирается из базы локаций
     сайта: начните вводить город, штат или индекс — появятся подсказки; «определить
     автоматически» возвращает найденную по лоту. Объём, порт и доплаты — в строке «Ещё параметры».
     Страховка груза (1%) включена всегда и отключить её нельзя;
   - **фото** — клик по снимку выбирает его для поста, кнопки «Первые 10» и «Скачать выбранные»;
   - **текст поста** — переключатель Telegram / Facebook / Instagram и редактируемый текст.
4. Внизу закреплена кнопка публикации, рядом — сколько фото выбрано и итоговая сумма.

Ставка и любые параметры пересчитывают смету и текст поста мгновенно. Текст перестаёт
обновляться сам, как только вы правите его руками, — вернуть шаблонный вид можно кнопкой
«Пересобрать по шаблону».

## Настройки

### Telegram
1. `@BotFather` → `/newbot` → скопировать токен
2. Добавить бота в канал **администратором** с правом «Публиковать сообщения»
3. В настройках расширения: токен + канал (`@имя_канала` или `-100…`)
4. Кнопка «Проверить подключение» покажет, видит ли бот канал

### API аукционов
- **Через сайт apexauto.md** (по умолчанию) — расширение дергает `https://apexauto.md/api/lot?url=…`,
  ключ `AUCTIONS_API_KEY` остаётся на Vercel. Ничего дополнительно вводить не нужно.
- **Напрямую в auctionsapi.com** — вставить ключ в настройки; расширение само ходит в API.
  Ключ хранится только в этом браузере (`chrome.storage.local`).
- **Не использовать API** — данные берутся только со страницы.

Данные со страницы всегда в приоритете, API дополняет пустые поля и добавляет фотографии.

### Facebook / Instagram
Нужны Page ID + Page Access Token (`pages_manage_posts`, `pages_read_engagement`), для Instagram —
бизнес-аккаунт, привязанный к странице, IG User ID и токен с `instagram_content_publish`.
Instagram публикует **только по публичным ссылкам на фото** — картинки Copart/IAAI подходят,
локальные файлы нет.

Если токенов нет — работают «Копировать текст» и «Скачать выбранные» фото: вставить вручную.

### Откуда берётся расчёт

Расширение **не считает само** — оно спрашивает калькулятор сайта:
`POST https://apexauto.md/api/calc`. Эндпоинт использует `calc-core.js` — тот же модуль,
которым считает калькулятор на главной и карточка лота в каталоге. Один источник формул:
поменяли тариф в `calc-core.js` → сайт, менеджеры и расширение обновились разом.

Под итогом всегда написано, чей это расчёт:
- `Считал калькулятор apexauto.md` — цифры с сайта;
- `Сайт не ответил (…) — расчёт по локальной копии формул` — офлайн-запас (те же формулы,
  но обновляются только вместе с расширением);
- `Локальный расчёт (выбран в настройках)` — режим переключён вручную.

Курс валют по умолчанию берётся автоматически — тот же источник, что у сайта (БНМ, резерв
fxratesapi), и под итогом написано, какой курс применён. В настройках можно переключить
на ручной и задать свои значения.

### Хэштеги

Две группы. `{{hashtags}}` — постоянные, они в настройках (отдельно RU и RO).
`{{autotags}}` — расширение подбирает само под конкретную машину: марка, марка+модель,
топливо, тип кузова, аукцион. Повторы с постоянными тегами отбрасываются.
Не нужны автотеги — уберите `{{autotags}}` из шаблона.

### Язык поста

Рядом с переключателем сетей в панели стоят кнопки **RU / RO**. Переключение меняет не только
подписи, но и значения: `Front End` → «Перёд» / «Față», `Run and Drive` → «Заводится и едет» /
«Pornește și merge», пробег «миль (км)» / «mile (km)». Румынские шаблоны и хэштеги —
отдельные поля в настройках; если румынский шаблон пуст, берётся русский.

### Шаблоны
Три шаблона (Telegram / Facebook / Instagram) редактируются в настройках.
Подстановки вида `{{lot}}`, `{{damage}}`, `{{totalUsd}}` — полный список выведен на странице настроек.
**Строка, в которой хотя бы одна подстановка пустая, в пост не попадает** — поэтому шаблон можно
писать «с запасом», лишние строки отпадут сами.

## Как устроен сбор данных

Три независимых источника сливаются в одну карточку (первый непустой выигрывает):

1. **DOM страницы** — универсальный сбор пар «подпись → значение» (`dl/dt/dd`, таблицы, `label + span`,
   строки вида `VIN: XXX`). Не завязан на конкретные CSS-классы, поэтому переживает редизайн.
2. **Внутренние JSON-эндпоинты аукциона** — Copart `/public/data/lotdetails/solr/{lot}` и список фото,
   IAAI `#ProductDetailsVM` и `GetJsonImageDimensions` (запросы идут из вкладки, с вашими куками).
3. **API аукционов** (см. выше).

Неопознанные поля не выбрасываются — они попадают в блок «Все поля, которые отдал аукцион».
Если аукцион введёт новую подпись, она сразу появится там, а перевести её в основные поля —
это одна строка в `src/common/dictionary.js` (`LABEL_ALIASES`).

## Структура

```
manifest.json
src/common/     util, dictionary (переводы RU/RO), extract-core (парсер), calc (формулы сайта),
                templates, settings, journal (журнал/черновики/напоминания), api-client,
                publish, image-dedupe
src/content/    copart.js, iaai.js, content.js (кнопка + панель на странице), inject.css
src/background/ service-worker.js — сбор из вкладки, публикация, скачивание фото
src/ui/         panel.html/css/js (панель), options.html/css/js (настройки)
test/           fixture-lot.html — страница-заглушка для проверки парсера без аукциона
```

Проверка парсера без аукциона: `node local-server.js`, затем
`http://localhost:8081/chrome-extension/test/fixture-lot.html` — страница покажет,
что распознал парсер, какой вышел расчёт и как выглядит пост.

Проверка самой панели без аукциона: `src/ui/panel.html?demo=1` — открывается с демо-лотом,
удобно править вёрстку и формулы расчёта, не заходя на Copart.

## Ограничения, о которых стоит знать

- **VIN и часть данных Copart** видны только залогиненному пользователю — расширение работает
  в вашей сессии, поэтому сначала войдите в аккаунт аукциона.
- **Внутренние эндпоинты аукционов не документированы** и могут отвечать 403 при защите от ботов.
  Тогда данные берутся из DOM и API аукционов — карточка соберётся, просто источников будет меньше.
- **Базы площадок в расширении нет** — тарифы и порт присылает сайт (`/api/locations` и `/api/calc`).
  Обновили тарифы в `locations.js` на сайте — расширение подхватит их сразу, переустанавливать нечего.
  Обратная сторона: без связи с сайтом наземная доставка считается только по последней
  выбранной площадке.
- **Курсы валют** задаются в настройках вручную (по умолчанию 17.45 / 20.28) — они не тянутся автоматически.
- Расширение не собирает ничего в фоне: данные читаются только когда вы открыли панель на лоте.

## Память между сессиями

- **Журнал публикаций.** Каждая удачная публикация записывается (лот, сеть, язык, время).
  При следующем открытии того же лота в шапке появляется отметка
  «✓ Уже публиковали 20 августа в 01:22 · Telegram» — чтобы один лот не ушёл в канал дважды.
- **Черновик.** Правки текста и ставка сохраняются автоматически и восстанавливаются,
  когда лот открыт заново. «Пересобрать по шаблону» и удачная публикация черновик убирают.
- **Напоминание о торгах.** Кнопка 🔔 в шапке ставит будильник за час до аукциона
  (за 10 минут, если до торгов меньше часа). В нужный момент Chrome покажет уведомление,
  клик по нему открывает лот. Время берётся из даты торгов, как её показывает аукцион.

Всё лежит в `chrome.storage.local`: журнал — последние 400 публикаций, черновики — 40 лотов.
