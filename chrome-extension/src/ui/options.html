Apex Auto — настройки

Telegram-канал

Создайте бота у @BotFather, добавьте его администратором в канал с правом «Публиковать сообщения». Чат — это @имя_канала или числовой id вида -1001234567890.

API аукционов

Расширение забирает данные со страницы лота и дополняет их через API. «Через сайт» — запрос идёт на /api/lot apexauto.md, ключ остаётся на сервере. «Напрямую» — расширение само ходит в auctionsapi.com с ключом ниже (ключ хранится только в этом браузере).

Facebook (страница)

Нужен Page ID и Page Access Token с правами pages_manage_posts, pages_read_engagement. Токен берётся в Meta for Developers → Graph API Explorer, лучше долгоживущий.

Instagram (бизнес-аккаунт)

Instagram публикует только по публичным ссылкам на фото и требует бизнес-аккаунт, привязанный к странице Facebook. Нужен IG User ID и токен с правами instagram_content_publish.

Расчёт «под ключ»

Цифры берутся у калькулятора apexauto.md — чтобы расширение, сайт и менеджеры считали одинаково. Локальный режим нужен только когда сайт недоступен: формулы те же, но обновляются вместе с расширением.
