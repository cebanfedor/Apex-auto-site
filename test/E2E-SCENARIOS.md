# E2E-сценарии (Playwright) — описание

По решению владельца тяжёлый Playwright-раннер не устанавливаем (проект без сборки,
«не добавлять зависимости»). Ниже — готовые сценарии для ручной проверки или для
будущей автоматизации, если Playwright всё же поставят. Три критических пути ×
(happy path + ошибка). Юнит-логика уже покрыта `node:test` (`npm test`).

## 1. Калькулятор стоимости (`/`)
**Happy path**
1. Открыть `/`, доскроллить до калькулятора (`#calculator`).
2. Выбрать аукцион, локацию, тип, топливо; ввести `Стоимость лота = 12000`.
3. Ожидать: `#total` — конечная сумма вида `$NN,NNN`, `#breakdown` заполнен.
4. Переключить валюту (USD/MDL/EUR) — сумма пересчитывается, без `$NaN`/`$∞`.

**Ошибки/границы** (регресс P2-1/P2-2)
1. Очистить поле курса `#usdMdl` → `#total` остаётся конечным (берётся defaultValue), НЕ `$∞`/`$NaN`.
2. Ввести `#lotPrice = -5000` → итог не отрицательный (цена клэмпится к 0).
3. Ввести `#lotPrice = 1e999` → итог конечный, без `$∞`.

## 2. Заявка / лид
**Happy path — форма аукционов (`/auctions`, модалка лота)**
1. Открыть лот → «Оставить заявку». Заполнить имя + телефон (`+37368…`).
2. Submit → статус «Заявка отправлена», модалка автозакрывается ~2.2с.
3. Проверить: кнопка была disabled во время отправки; повторный клик в окне успеха не шлёт пустой запрос (регресс P3-1).

**Happy path — формы главной (`/`, подбор / контакт)**
1. Заполнить `#selectionForm` (имя + контакт) → submit.
2. Проверить сеть: ушёл `POST /api/auctions?action=lead` (лид сохраняется на сервере, регресс P0-1); показан успех после ответа.

**Ошибки**
1. Отключить сеть, отправить заявку аукциона → дружелюбное сообщение с CTA в Telegram, НЕ сырое «Failed to fetch» (регресс P1-2).
2. Ввести телефон-мусор `aaaaa` → сервер 400 «Укажите телефон… или Telegram» (P2-3).

## 3. Проверка VIN (`/auctions?vin=…` и умный поиск)
**Happy path**
1. Ввести валидный 17-значный VIN → открывается отчёт/деталь лота.

**Ошибки** (регресс P2-4)
1. Ввести 16-значный или с буквами I/O/Q → сообщение «Некорректный VIN: 17 символов, без I, O, Q», запрос к API не уходит.
2. Валидный VIN несуществующей машины → «лот не найден» с CTA оставить заявку (это НЕ то же, что ошибка формата VIN).
